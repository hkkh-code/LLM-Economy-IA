# DeepEconomy - LLM Economy IA

DeepSeek Harness modifié avec Dashboard et Chat intégré pour gérer vos tokens IA gratuitement.

## 🚀 Installation

```bash
git clone https://github.com/hkkh-code/LLM-Economy-IA.git
cd LLM-Economy-IA/deepeconomy
pnpm install
pnpm run dev
```

Le dashboard s'ouvre automatiquement dans votre navigateur !

## ✨ Fonctionnalités

- 🎯 **7 Providers Gratuits**: DeepSeek, Groq, Google AI, Cohere, Anthropic, Mistral, Together AI
- 📊 **Dashboard**: Statistiques de tokens utilisés/économisés
- 💬 **Chat Intégré**: Discutez directement avec les modèles
- 🔑 **Gestion API Keys**: Ajoutez vos clés API dans le dashboard
- 🚀 **Boot Screen**: Animation de démarrage style custom ROM
